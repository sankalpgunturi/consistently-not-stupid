# Gaps

Choices filled in so the desk could run. Argue with these after the flight. None of them are a promise that the book makes money.

- **Research does not gate paper entries.** The user explicitly removed the historical-evidence requirement from the ten-minute paper experiment. The first structurally eligible quote per event is still followed to its official outcome for retrospective analysis. These observations are not fills or ledger profit, and distinct events may share risks. Minimum sample size, Wilson confidence bounds and historical edge do not block entries. Legacy replay (`entry_window_minutes=0`) retains its original historical rule. Probability, timing, fees, liquidity, stability, exposure limits and executable depth still apply.
- **Live sending does not exist.** There is no arm button and no order POST. Adding signed orders, acknowledgements, reconciliation, and a kill path is a later reviewed change. Thirty days of paper is an observation window, not evidence the book won. An open clip from a venue this desk no longer reads, including an older Polymarket fill, is closed at cost when the book opens and the cash is returned.
- **The Decisions drop threshold is 0.6.** A clip is removed only when the matching answer is `drop` and the probability on `drop` is at least 0.6. Below that, or on any bad body, the deterministic set stands. The model cannot add a market.
- **Overrides only tighten, and the floor is 90%.** One step per click, inside the rails. The automatic governor, including a model suggestion, moves one step and only after a settlement that was not already counted. An unchanged book does not ratchet. `min_probability` cannot fall below 0.90. The scan clock is not a risk knob. A tighten that lands while a scan is still reading the book is applied to that scan's fills.
- **No login.** The owner explicitly requested that anyone with the permanent Cloudflare dashboard URL have the same controls. The Worker checks its own CSRF token and rejects foreign origins; a secret-authenticated publisher relays commands to the Mac, where persistent command IDs prevent replay. The engine still runs on the Mac. The local desk requires a separate CSRF token. `Origin` and `Host` have to be localhost or the host passed to `--host`, including on the state read and the snapshot socket. An IPv6 bind is the full address, with or without brackets. A wildcard bind such as `0.0.0.0` trusts only loopback names. That is not an account system.
- **Fees use the series multiplier and round up to the next cent.** Each scan reads the public series metadata for favorites. Unknown schedules block admission. Exit marks retain the entry fee schedule. Account-specific precision, later fee changes on an open position, and per-order rounding rebates are not simulated.
- **The scan is not the whole venue.** Near-term discovery prioritizes the next ten minutes, then the next hour and day, plus an unfiltered open-market allocation. With eight market-list requests, it reserves one per broader window and can spend five on 1,000-market pages nearest-first. Unused requests pass to later windows; a warning records when the nearest window still has more pages at its cap. These close-time discovery windows do not replace the explicit expected-outcome check at admission.
- **Paper entries hold to the official result.** The user removed automatic stop-loss exits. Price declines change the mark but do not sell the position. The operator may still close manually. Legacy replay retains its stop rule.
- **Ten minutes is the outcome window, not the scan interval.** Background quote monitoring and evaluation target one-second cadence, with bounded discovery every 30 seconds. A shared public-read ceiling and adaptive throttling constrain API traffic. Model review and fill checks can delay admission while quote monitoring continues; positions are also marked between scans. Quotes and entry timing are checked again before a fill. An unchanged book gets routine model commentary at most once every ten minutes; proposed buys and changed review inputs trigger review sooner. Deterministic screening continues each scan.
- **Settlement waits for Kalshi `result`.** A clip settles when `result` is `yes` or `no`. A price near 0 or 1 does not settle it. If the flag is missing, the position stays open. A settled payload that omits the bid and the ask still settles from the winner.
- **A person cannot force a buy** the fee rule, the horizon, or the depth check refused.
- **Paper size is the displayed touch.** Kalshi publishes bids, so the other side's bids are the ask. An unfamiliar payload is a refusal, not a fill.
